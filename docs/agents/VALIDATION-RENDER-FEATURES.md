# VALIDATION-RENDER-FEATURES.md — render feature validators

Part of the [validation index](VALIDATION.md); its rules for citing a
validator apply. Each row proves one render feature: a shader contract suite
or a metric over native captures. Open it for a change to that feature, or
when an issue or plan names one of its validators. A row added here also adds
its name to this page's line in the index's area table.
