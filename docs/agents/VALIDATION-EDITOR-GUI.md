# VALIDATION-EDITOR-GUI.md — editor and GUI validators

Part of the [validation index](VALIDATION.md); its rules for citing a
validator apply. Open it for a change to the voxel editor, GUI widgets or
input routing, or the trixel fonts. A row added here also adds its name to
this page's line in the index's area table.

| Validator | Proves | Run | CI |
|---|---|---|---|
| Editor screen alignment | raw cursor samples agree with rendered faces at cardinal, diagonal and intermediate yaw; grid support/occlusion, translucent whole-cell preview and F12 capture | `python3 scripts/gui-verify.py IRVoxelEditor -- --gui-session screen_alignment --gui-layout-check`, then `python3 scripts/editor-screen-alignment.py --log <run.log> --screenshots <capture-dir>`; repeat with `--config-preset test/alignment_letterbox.lua` | render-harness-tests.yml runs the pixel oracle’s positive/negative controls; native captures run manually |
| Camera gesture ownership | navigation suppresses sculpt/gizmo edits through release, fresh editing resumes, and inward placement stays reachable | `CameraGesture.*`, `GizmoDragGestureTest.*`, `GizmoDragResetTest.*`; `python3 scripts/gui-verify.py IRVoxelEditor -- --gui-session camera_gestures --gui-layout-check`; `--gui-session place_below` | C++ unit tests plus manual native GUI capture |
| Editor Box/Line | real toolbar selection, floor preview/commit/undo/cancel and isolation from overlapping parts at intermediate yaw | `--gui-session region_tools --gui-layout-check` through `scripts/gui-verify.py` | native GUI gate |
| Editor shadow return | fixed authored geometry restores identical lit/unshadowed pixels at repeated cardinal and intermediate poses | `--gui-session shadow_rotation`, then `python3 scripts/editor-shadow-rotation.py --log <run.log> --screenshots <capture-dir> --surface <0|1> --output <dir>`; compare runs with `IR_PERAXIS_SURFACE_LIGHTING=0` and `1` | render-harness-tests.yml runs metric controls; native captures are diagnostic, not a geometric correctness oracle |
| GUI behaviour | GUI-ASSERT shots pass for a creation; participants: `IRVoxelEditor`, `IRLuaWidgetsDemo`, `IRUIWidgetsDemo`, `IRShapeDebug`, `IRCanvasStress`, `IRFontMaker`, `IRLauncher` (per-target flags: the skill's participant table) | `gui-verify` skill; `python3 scripts/gui-verify.py <Creation>` | none |
| GUI trixel font art (large and small sets) | an edited glyph still follows the lattice rules in [`gui-trixel-display.md`](../design/gui-trixel-display.md) (no lone triangles, diamond-chain diagonals, pointed stem ends; the small set's own rules) | `fleet-run IrredenEngineTest --gtest_filter='TrixelFont.*'` (coverage, lone triangles, duplicate bitmaps); `python3 scripts/trixel-font-preview.py engine/render/include/irreden/render/trixel_font.hpp --out sheet.png` (add `--set small` with `trixel_font_small.hpp`) and inspect the sheet; `--mode pixelated` previews the `gui_pixelated` path | none |
| GUI scale-1 text legibility | the screen composite gives exposed LARGE and SMALL glyph rows solid owned samples and no across-edge halo at the 2x1-pixel texel footprint, while both backends keep the larger-footprint box filter | `python3 scripts/render-verify.py --target IRShapeDebug` (`text_scale1_legibility:text_size_sample:text-stroke-contrast` reports both set row counts, `min_stroke_coverage >= 0.95`, `max_halo_coverage <= 0.05`, `min_stroke_to_halo_ratio >= 10`); `python3 scripts/tests/test_render_gui_text_minimum_footprint.py` | render-harness-tests.yml through `scripts/tests/**`, shader paths, and the shape-debug manifest |
